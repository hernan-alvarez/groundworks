# groundworks

Playbooks for doing product and go-to-market work with AI agents. Each one is a Markdown file you hand to your agent. It reads the whole thing, then works through it with you: it drafts, asks about the gaps, and argues with you until the work holds up.

These come from real work, not theory. Each one says where it came from and what it assumes.

## Playbooks

* **[Agentic Product and GTM Kickstart Playbook](agentic-product-gtm-kickstart.md).** Takes a product from a first strategy doc through positioning, a launch, and a growth plan, with agents drafting each document and you making the calls. You can start with just a chat agent connected to a shared wiki.

## How to use one

1. Read Part 1 yourself. It covers what you'll end up with, the tools, and how it all fits together.
2. Give your agent the whole file and say "Read all of this, then start at Phase 0."
